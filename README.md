# EV Control website

Responsive static website for an EV software engineering company serving passenger-car OEMs and Tier 1 suppliers from Türkiye and San Francisco.

## Preview

Open `index.html` directly, or serve this directory using a static HTTP server. No package installation or build step is required.

## GitHub Pages

After committing the files to the selected repository, open **Settings → Pages**, choose **Deploy from a branch**, and select the main branch and root directory. All asset paths are relative and support repository subpaths.

## Website

Published using GitHub Pages at https://evcontrol.akinozturk.com/ from `akinozturk/ev-control`.

## Brand and contact updates

- Approved website name: **EV Control**, matching `evcontrol.akinozturk.com`.
- Add the approved public contact address. No contact email was assumed, and no contact form sends or stores data.

## Features

- VCU, BMS, motor-control, and on-board charger (OBC) service descriptions.
- Delivery process, locations, and engagement models.
- Downloadable project brief, responsive navigation, keyboard focus states, and reduced-motion support.
- No analytics, cookies, remote fonts, external images, or runtime dependencies.

The website intentionally excludes business-plan financial projections and internal sales targets. It makes no customer, certification, or production-track-record claims.
